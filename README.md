# Agenda de Contactos actividad semana 15

## Descripción

Este proyecto consiste en un programa sencillo desarrollado en Python que permite registrar y administrar contactos telefónicos. El programa utiliza un **diccionario** para almacenar los nombres y números de teléfono.

## Objetivo

Desarrollar un programa que utilice una colección de datos para resolver un problema sencillo de la vida real, aplicando operaciones básicas sobre los datos almacenados.

## Funcionalidades

El programa permite:

* Agregar nuevos contactos.
* Mostrar todos los contactos registrados.
* Buscar un contacto por su nombre.
* Eliminar un contacto.
* Salir del programa.

## Colección utilizada

Se utiliza un **diccionario (`dict`)**, donde:

* La clave corresponde al nombre del contacto.
* El valor corresponde al número telefónico.

Ejemplo:

```python
contactos = {
    "Juan": "0991234567",
    "María": "0987654321"
}
```

## Conclusión

Este programa permite aplicar el uso de diccionarios en Python para resolver una situación cotidiana. Además, permite practicar operaciones como agregar, buscar, mostrar y eliminar información almacenada en una colección de datos.
